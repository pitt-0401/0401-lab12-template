# Trivia!

## Overview
This program contains a question bank (`questions.csv`) where trivia questions can be added. 
Per round, a user answers every question in `questions.csv` and receives immediate feedback whether they answered the question correctly. After a round, the overall result is displayed in a pop-up.

## Run
Run `Trivia` from the project folder (the one that contains `questions.csv`), otherwise no questions are loaded.

## Add a question
Add one more question about your favorite/least favorite Java topic to `questions.csv`.
- Format: `Question, Option A, Option B, Option C, Correct answer (A, B, or C)`
- No commas inside the question or the options
